The stat initializer is deliberately a base-formula building block. It returns a value only when species, level, six IVs, nature stat indices, form-valid ability and up to four canonical move IDs are explicitly provided. The ability-index helper follows pinned regular/hidden roll order but does not create a complete Pokémon actor. `statsAreBaseFormulaOnly` stays true so consumers cannot mistake the result for full upstream stats. No battle parity percentage is claimed.
