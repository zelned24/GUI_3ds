# PokéRogue para Old Nintendo 3DS XL

1. Runtime nativo C++ en `project/`, devkitARM/libctru/Citro2D; bridge QuickJS opcional actualmente habilitado por el Makefile.
2. Fuentes pinned, normalización y assets en `tools/js/` y `scripts/`; pantallas de 400×240 y 320×240.
3. Referencia de estructura y comandos: [README](README.md).
4. Estado verificado, fallos y límites: [MIGRATION_STATUS](docs/MIGRATION_STATUS.md).
5. Pendientes: [checklist](docs/progress/IMPLEMENTATION_CHECKLIST.md).
6. Reglas para agentes: [AGENTS](AGENTS.md).

No declarar Classic, menús, guardado, paridad completa ni rendimiento Old 3DS terminados a partir de la existencia de clases o de una compilación exitosa.
